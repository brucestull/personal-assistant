# True North Quick Start: Core Values → Goals → Milestones → Tasks

Use this app to connect what you do today to what matters most long-term.

If you ever feel stuck, zoom out:
- Tasks should support Milestones
- Milestones should move Goals forward
- Goals should express Core Values

---

## The 4 levels (what each one means)

### CoreValue (North Star)
A guiding principle you want to live by.
- Example: Integrity, Health, Family, Learning, Service

Fields to fill:
- name
- definition (your words)
- is_active
- order

---

### Goal (Outcome / Direction)
A meaningful outcome that expresses a Core Value.
- Example: "Build a consistent sleep routine"

Fields to fill:
- value (CoreValue)
- title
- slug (auto)
- status (active/draft/etc.)
- description (optional)
- target_date (optional)
- is_active
- order

---

### Milestone (Checkpoint)
A checkpoint that proves the goal is progressing.
- Example: "Complete 10 nights of bedtime routine"

Fields to fill:
- goal
- description
- slug (auto)
- due_date (optional)
- notes (optional)
- is_completed

---

### Task (Next action)
A small, clear action you can actually do.
- Example: "Put phone charger outside bedroom"

Fields to fill:
- milestone
- content
- status (todo/doing/done/skipped)
- due_date (optional)
- is_completed

---

## Setup in 15 minutes

### 1) Create 2–4 Core Values
Pick the ones you truly care about.
Write a short definition for each.

Starter ideas:
- Integrity
- Health
- Family Connection
- Growth / Learning
- Reliability
- Compassion

---

### 2) Add 1–2 Goals per Core Value
Pick goals you can realistically work on.

Goal title examples:
- Integrity: "Practice honest communication weekly"
- Health: "Build a consistent sleep routine"
- Family: "Plan intentional family time each week"

Set status = active for what matters now.

---

### 3) Add 2–3 Milestones per Goal
Define what “progress” looks like.

Milestone examples:
- "Set up the environment so this is easy"
- "Complete 4 weekly practice sessions"
- "Create a simple plan and follow it for 2 weeks"

---

### 4) Add 3–6 Tasks per Milestone
Make tasks small and clear. Start with verbs.

Task examples:
- "Write 3 sentences: what I’m avoiding saying and why"
- "Set an alarm for bedtime routine"
- "Text and schedule a 1-hour visit/call"
- "Lay out CPAP supplies before bed"

---

## Mini example (one value, one goal)

### CoreValue: Health
- definition: I protect sleep, movement, and nutrition so I can function well.

#### Goal: Build a consistent sleep routine
- status: active
- target_date: 2026-03-15

##### Milestone: Set up a simple bedtime routine
- Tasks:
  - Decide a consistent lights-out time (weekdays)
  - Put phone charger away from bed
  - Prepare CPAP supplies so it’s easy nightly

##### Milestone: Complete 10 nights of the routine
- Tasks:
  - Do routine tonight (mark done)
  - If I miss a night, write 1 sentence: what blocked me?
  - Remove the biggest blocker (adjust the routine)

---

## Fast “alignment check” (use this constantly)

Before creating a Task, ask:
- "If I do this task, how does it support the value?"

If you can’t answer clearly:
- rewrite the task smaller/clearer, or
- move it under a different milestone/goal/value.

---

## Weekly review (5 minutes)

- Are my active tasks still aligned with my values?
- Do I have too many active goals?
- What milestone should I focus on next?
- What’s the next smallest task I can do?

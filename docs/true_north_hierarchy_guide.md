# True North: Core Values → Goals → Milestones → Tasks (User Guide)

This app helps you connect day-to-day actions to the bigger things you care about.

The idea is simple:
- You decide what matters most (Core Values)
- You define outcomes that express those values (Goals)
- You break each goal into checkpoints (Milestones)
- You create small, doable actions (Tasks)

When you use the hierarchy well, your short-term work stops feeling random. It becomes “proof” that you are living your values.

---

## The Hierarchy (in plain language)

### CoreValue
A **CoreValue** is a guiding principle you want to live by.
- It is not a task.
- It is not a one-time achievement.
- It is a “north star” you can steer by.

Examples:
- Integrity
- Health
- Family
- Learning
- Courage
- Compassion
- Reliability
- Growth
- Service
- Creativity

Fields you fill in:
- name: Short label (e.g., "Integrity")
- definition: Your personal meaning (1–6 sentences)
- is_active: Whether you’re focusing on it right now
- order: Where it appears in your lists

Good definition examples:
- Integrity: "I tell the truth, keep promises, and do the right thing even when it is uncomfortable."
- Health: "I protect my sleep, movement, and nutrition so I can function well and show up for others."

---

### Goal
A **Goal** is an outcome or direction that expresses a CoreValue.
A goal should answer:
- “If I lived this value more, what would be different in my life in a measurable way?”

Goals can be short-term or longer-term, but they should be clear enough to plan.

Fields you fill in:
- value: Which CoreValue it supports
- title: Short goal statement
- slug: Auto-filled from title (editable)
- description: Optional details about success criteria / why it matters
- status: draft / active / paused / done / archived
- start_date: Optional
- target_date: Optional
- is_active: Quick toggle
- order: Where it appears in your lists

Good goal title patterns:
- "Practice honest communication weekly"
- "Build a consistent sleep routine"
- "Spend meaningful time with family each week"

---

### Milestone
A **Milestone** is a checkpoint that moves a Goal forward.
Milestones are smaller than goals, but bigger than tasks.

A milestone should answer:
- “How will I know this goal is progressing?”
- “What are the major steps or checkpoints?”

Fields you fill in:
- goal: Which Goal it supports
- description: Clear checkpoint statement
- slug: Auto-filled from description (editable)
- notes: Optional details (definition of done, context, constraints)
- due_date: Optional
- is_completed: Yes/No
- completed_at: Optional timestamp
- order: Where it appears in the goal

Good milestone description patterns:
- "Complete 4 weekly practice sessions"
- "Set up the environment so this becomes easy"
- "Finish the first draft / first version"

---

### Task
A **Task** is the smallest “doable” action.
Tasks should be concrete enough that you can do them without confusion.

A task should answer:
- “What is the next physical action?”
- “What would I literally do next?”

Fields you fill in:
- milestone: Which Milestone it supports
- content: The actual task instructions
- status: todo / doing / done / skipped
- due_date: Optional
- is_completed: Yes/No
- completed_at: Optional timestamp
- order: Where it appears in the milestone

Good task content patterns:
- Start with a verb: "Write", "Call", "Schedule", "Walk", "Prepare", "Clean", "Review"
- Make it small: 5–30 minutes when possible
- Include clarity: place, tool, definition-of-done

## How to Use the App (simple workflow)

### Step 1 — Create 2–5 Core Values
Start small. Pick values you *actually* care about.
Write definitions in your own words (not a dictionary definition).

### Step 2 — Add 1–3 Goals per Core Value
Pick goals that are realistic and meaningful.
Set the status to "active" for the ones you want to work on now.

### Step 3 — Break Goals into Milestones
Think in checkpoints, not in tiny steps yet.
Milestones are where you define what “progress” looks like.

### Step 4 — Add Tasks under each Milestone
Tasks are the weekly/daily actions.
If you get stuck, make the next task smaller and clearer.

### Step 5 — Review weekly
- Are your tasks still aligned with the value?
- Are you working on too many goals at once?
- Do you need to pause/archive something?

## Example Hierarchy (outline view)

### CoreValue: Integrity
- definition: I tell the truth, keep promises, and do the right thing even when uncomfortable.

#### Goal: Practice honest communication weekly
- status: active
- target_date: 2026-03-31
- description: Build a habit of direct, kind honesty instead of avoidance.

##### Milestone: Identify common avoidance moments
- due_date: 2026-02-20
- notes: Track situations where I hold back or people-please.
- Tasks:
  - Write a list of 5 situations where I avoided being honest this month.
  - Pick the top 1 situation that matters most.
  - Write a 3-sentence truth statement I could say next time.

##### Milestone: Have 4 honest conversations (one per week)
- due_date: 2026-03-31
- Tasks:
  - Schedule a short check-in conversation (text or call).
  - Write the “opening sentence” before the conversation.
  - Afterward, write 2 notes: what went well + what to improve.

##### Milestone: Reduce avoidance triggers in my environment
- due_date: 2026-03-15
- Tasks:
  - Identify 2 people/situations where I regularly avoid truth.
  - Define a boundary sentence for each.
  - Practice the boundary sentence out loud 3 times.

### CoreValue: Health
- definition: I protect sleep, movement, and nutrition so I can function well and support my life.

#### Goal: Build a consistent sleep routine
- status: active
- target_date: 2026-03-15
- description: Sleep is the foundation for mood, focus, and resilience.

##### Milestone: Set up a simple bedtime routine
- due_date: 2026-02-14
- Tasks:
  - Decide a consistent “lights out” time for weekdays.
  - Put charger outside the bedroom (or away from bed).
  - Prepare CPAP supplies and make it easy to use nightly.

##### Milestone: Complete 10 nights of the routine
- due_date: 2026-02-28
- Tasks:
  - Do bedtime routine tonight (track as done).
  - If I miss a night, write one sentence: what blocked me?
  - Adjust the routine to remove the biggest blocker.

##### Milestone: Add a morning reset (5–10 minutes)
- due_date: 2026-03-10
- Tasks:
  - Pick a simple morning start: water + light movement.
  - Do it 3 mornings this week.
  - After 1 week, decide if it’s worth keeping.

- due_date: 2026-02-12

  - Keep a running list of topics/questions to ask.

## Tips for Making This Work

- Keep Core Values few and clear.
- Keep Goals meaningful but not overwhelming.
- Use Milestones to define “progress.”
- Make Tasks small enough to actually do.
- If you avoid a task repeatedly, it’s too big or unclear. Shrink it.
- Prefer consistency over intensity.

---

## Optional: A simple self-check question

Before you create a Task, ask:
- “If I do this task, how does it support the value?”

If the answer is unclear, either:
- move the task under a different milestone/goal/value, or
- rewrite it so it clearly supports what matters.

# True North Admin Cheat Card (CoreValue → Goal → Milestone → Task)

Use this hierarchy to make daily actions match what matters most.

---

## The one-sentence meaning of each level

- CoreValue = What I want to live by (north star)
- Goal = What I’m trying to achieve/change that expresses the value
- Milestone = Proof/checkpoint that the goal is progressing
- Task = The next clear action I can do

---

## 60-second workflow (use in Django Admin)

1) Create 2–4 CoreValues (write definitions in your own words)
2) Add 1–2 Goals under each CoreValue (set status=active for what matters now)
3) Add 2–3 Milestones under each Goal (define what “progress” looks like)
4) Add 3–6 Tasks under each Milestone (small, clear, verb-first)

---

## Alignment check (most important rule)

Before adding a Task, ask:
- “If I do this task, how does it support the CoreValue?”

If unclear:
- rewrite the task smaller/clearer, OR
- move it to a different milestone/goal/value

---

## Good defaults (keep it simple)

CoreValue definition:
- 1–6 sentences, personal meaning (not dictionary)

Goal title:
- short + specific + meaningful
- examples:
  - "Build a consistent sleep routine"
  - "Practice honest communication weekly"
  - "Plan intentional family time each week"

Milestone description:
- measurable checkpoint
- examples:
  - "Complete 10 nights of routine"
  - "Have 4 weekly practice sessions"
  - "Create a weekly plan and follow it for 2 weeks"

Task content:
- verb-first, small, concrete
- examples:
  - "Set an alarm for bedtime routine"
  - "Write the opening sentence for the conversation"
  - "Text and schedule a 1-hour call"

---

## Weekly review (5 minutes)

- Do my tasks still match my values?
- Do I have too many active goals?
- What milestone is my next focus?
- What’s the next smallest task I can do?
